Mode Écouteurs + PC

Votre appel (WhatsApp, Zoom, Teams, Google Meet) et Traducteur Live tournent sur le même PC. Deux câbles audio virtuels relient les deux : vous entendez le français dans vos écouteurs, votre interlocuteur n'entend que l'anglais. Aucun haut-parleur, aucun écho.

Le principe en un coup d'œil

Câble 1 — l'appel vers le traducteur (il parle anglais)

Interlocuteur→ App d'appel
Haut-parleur→ CABLE Input → CABLE Output
Mac : BlackHole 2ch→ Traducteur Live→ 🎧 Vos écouteurs (français)

Câble 2 — le traducteur vers l'appel (vous parlez français)

🎤 Votre micro→ Traducteur Live→ CABLE-A Input → CABLE-A Output
Mac : BlackHole 16ch→ App d'appel
Microphone→ Interlocuteur (anglais)

Les deux sens fonctionnent en même temps (deux sessions indépendantes). Coût : environ celui de deux sessions de traduction simultanées.

1Ce qu'il vous faut

  • Un PC sous Windows 10/11 ou un Mac sous macOS.
  • Chrome ou Edge à jour, ouvert sur eldo81.github.io/traducteur-live/.
  • Des écouteurs (Bluetooth ou filaires) connectés au PC.
  • Un micro : celui du PC ou un micro USB (recommandé). Le micro des écouteurs Bluetooth fonctionne, mais fait passer les écouteurs en qualité « casque/HFP », plus faible.
  • Les deux câbles virtuels : VB-CABLE et VB-CABLE A+B (Windows) ou BlackHole 2ch et 16ch (Mac).
  • La version ordinateur de votre application d'appel (WhatsApp Desktop, Zoom, Teams) ou Google Meet dans Chrome/Edge.

2Installer les câbles

Windows

  1. Ouvrez vb-audio.com/Cable/ et téléchargez VB-CABLE (gratuit, fichier .zip).
  2. Extrayez le zip (clic droit → Extraire tout).
  3. Clic droit sur VBCABLE_Setup_x64.exe → Exécuter en tant qu'administrateur → Install Driver.
  4. Redémarrez le PC.
  5. Sur la même page, téléchargez VB-CABLE A & B (donationware) et répétez les étapes 2 à 4 avec l'installateur de ce second paquet (fichier …Setup_x64.exe du zip, en administrateur). Seul le câble A sert ici (CABLE-A Input / CABLE-A Output).
  6. Vérifiez dans Paramètres → Système → Son que CABLE Input et CABLE-A Input apparaissent.

Mac

  1. Ouvrez existential.audio/blackhole (gratuit, saisissez votre e-mail pour recevoir les liens).
  2. Installez BlackHole 2ch, puis BlackHole 16ch.
  3. Ou, avec Homebrew, dans le Terminal :
brew install blackhole-2ch blackhole-16ch

Important : ne définissez jamais un câble comme périphérique par défaut du système. Sous Windows comme sur Mac, la sortie par défaut reste vos écouteurs ou vos haut-parleurs, l'entrée par défaut reste votre vrai micro. Seules l'app d'appel et Traducteur Live utilisent les câbles.

3Régler l'app Traducteur Live

  1. Ouvrez Réglages → Sortie audio et choisissez « Écouteurs + PC ».
  2. Cliquez sur « Détecter les périphériques audio », puis autorisez l'accès au micro.
  3. Choisissez les quatre périphériques :
    RéglageWindowsMac
    Mon microVotre vrai micro (PC ou USB)
    Mes écouteurs (traduction française)Vos écouteurs Bluetooth
    Son de l'appel (entrée)CABLE OutputBlackHole 2ch
    Vers l'appel (traduction anglaise)CABLE-A InputBlackHole 16ch
  4. Cochez « Lire la traduction française dans mes écouteurs ».
  5. Option : « Entendre la voix originale en fond » pour garder la voix de l'interlocuteur à faible volume.

4Régler l'application d'appel

Partout, les deux mêmes valeurs :

Dans l'app d'appelWindowsMac
MicrophoneCABLE-A OutputBlackHole 16ch
Haut-parleurCABLE InputBlackHole 2ch

WhatsApp Desktop

Pendant l'appel : bouton « … » → choisissez Microphone et Haut-parleur. Le libellé exact varie selon la version de WhatsApp. Si le menu n'existe pas, changez le micro et le haut-parleur par défaut dans les réglages son de Windows ou de macOS pendant l'appel, puis remettez-les après.

Zoom

Paramètres → Audio → Haut-parleur et Microphone. Décochez « Régler automatiquement le volume du micro ».

Microsoft Teams

Paramètres → Appareils → Haut-parleur et Microphone.

Google Meet

Pendant la réunion : ⋮ → Paramètres → Audio → Micro et Haut-parleurs.

5Pendant l'appel

  • Auto traduit dans les deux sens en même temps (usage normal).
  • Écoute traduit seulement l'interlocuteur (vous ne parlez pas).
  • Parle traduit seulement votre voix.
  • Parlez en phrases courtes, marquez une petite pause : la traduction démarre plus vite.
  • Votre interlocuteur entend la traduction avec un court décalage ; prévenez-le en début d'appel.
  • En fin d'appel, appuyez sur Stop, puis Exporter .txt pour garder la transcription.

6Test en 1 minute avant un appel important

  1. Lancez l'app en mode Auto.
  2. Sens anglais → français : lancez une vidéo YouTube en anglais dans un autre navigateur ou onglet, et envoyez sa sortie vers CABLE Input :
    • Windows : Paramètres → Système → Son → Mélangeur de volume (Windows 11) ou Paramètres → Son → Volume des applications et préférences de périphérique (Windows 10) → ligne du navigateur → Sortie = CABLE Input.
    • Mac : réglez temporairement la sortie de la vidéo sur BlackHole 2ch (menu son de l'app de lecture, ou Réglages Système → Son, puis remettez vos écouteurs juste après).
    Le français doit s'afficher et s'entendre dans vos écouteurs.
  3. Sens français → anglais : ouvrez l'Enregistreur vocal (Windows) ou QuickTime → Nouvel enregistrement audio (Mac), choisissez comme source CABLE-A Output / BlackHole 16ch, enregistrez en parlant français, puis réécoutez : vous devez entendre uniquement l'anglais.
  4. Remettez la sortie de la vidéo sur vos écouteurs (Windows : « Par défaut »).

Les deux tests passent : vous êtes prêt pour l'appel.

7Dépannage

SymptômeSolution
L'interlocuteur n'est pas traduitHaut-parleur de l'app d'appel = CABLE Input / BlackHole 2ch. Dans l'app, « Son de l'appel (entrée) » = CABLE Output / BlackHole 2ch.
L'interlocuteur n'entend rienMicro de l'app d'appel = CABLE-A Output / BlackHole 16ch. Dans l'app, « Vers l'appel » = CABLE-A Input / BlackHole 16ch.
L'interlocuteur entend mon françaisLe micro de l'app d'appel est votre vrai micro : remplacez-le par CABLE-A Output / BlackHole 16ch.
Je n'entends rienSélectionnez vos écouteurs dans « Mes écouteurs ». Vérifiez que « Lire la traduction française » est coché (sinon : sous-titres seulement).
La liste n'affiche que « Par défaut » ou aucun nomCliquez sur « Détecter les périphériques audio » et autorisez le micro.
Son robotique dans les écouteursLe micro Bluetooth est utilisé : choisissez le micro du PC ou un micro USB dans « Mon micro ».
« Ce navigateur ne permet pas de choisir la sortie audio »Utilisez Chrome ou Edge sur PC/Mac (pas sur téléphone, ni Safari, ni Firefox).
