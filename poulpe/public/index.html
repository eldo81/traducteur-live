Mode d'emploi en 6 étapes

    
    
      
  1. Éditeur → collez l'URL → Charger la page. La page s'affiche telle que le robot la voit.
    2. 
      
  2. Détection automatique : Poulpe propose les listes trouvées avec leurs colonnes. Cliquez sur « Utiliser ».
    Ou décrivez votre besoin en français et cliquez Configurer avec l'IA.
    3. 
      
  3. Affinez en cliquant dans la page : un clic sur un titre ajoute la colonne pour tous les blocs similaires (contour bleu = blocs, vert = champs).
    4. 
      
  4. Pagination : choisissez le type puis, en mode « Bouton suivant », cliquez sur le bouton de la page.
    5. 
      
  5. Tester (2 pages) pour valider, puis Enregistrer.
    6. 
      
  6. Onglet Tâches : lancez, planifiez, téléchargez CSV / Excel, ou recevez les nouvelles lignes par webhook n8n.
    7. 
    

    
Quand utiliser le mode IA

    
Pages mal structurées, mises en page qui changent souvent, PDF convertis en HTML : Claude lit le texte et renvoie les colonnes demandées. Plus lent et payant (clé API Anthropic), mais insensible aux changements de design.

    
Sites avec connexion

    
Ajoutez des actions type avec ${ENV:MON_MOT_DE_PASSE} et cochez « Garder la session ». Pour un site avec CAPTCHA ou double authentification : node src/cli.js login <id-tâche> <url> ouvre un vrai navigateur, vous vous connectez à la main, la session est réutilisée ensuite.

    
Usage responsable

    
Respectez les conditions d'utilisation des sites, robots.txt (activé par défaut) et le RGPD pour les données personnelles. Préférez les API officielles quand elles existent (modèles TED et Banque mondiale).
